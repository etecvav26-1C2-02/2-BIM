# Projeto Web Final

Site institucional do grupo para a materia Programacao Web 1, do curso de Desenvolvimento de Sistemas na ETECVAV.

## Integrantes

- Caua Balzaneli
- Daniel de Sousa Araujo
- Valentino Chagas Hoehne
- Miguel Marcelo

## Paginas

- **Home** - Apresentacao dos integrantes com um carrossel (slider) que mostra nome, cargo, foto e links para redes sociais de cada um.
- **About Us** - Missao e visao do grupo.
- **Services** - Servicos oferecidos: UI Design, UX Research e Web Development.

## Tecnologias

- HTML5
- CSS3 (um arquivo unico: `styles/index.css`)
- JavaScript puro (um arquivo: `src/script.js`)

## Funcionalidades

- Carrossel vertical com transicao suave entre os integrantes
- Navegacao por botoes anterior/proximo, pontos indicadores e setas do teclado
- Suporte a arrasto (swipe) em telas touch
- Reproducao automatica com pausa ao passar o mouse
- Layout responsivo (ajusta em telas menores)
- Navegacao fixa com efeito glassmorphism

## Estrutura de arquivos

```
Projeto Web Final/
  assets/          - Imagens (fotos, icones, logo)
  src/
    index.html     - Pagina inicial com o carrossel
    aboutus.html   - Pagina sobre nos
    services.html  - Pagina de servicos
    script.js      - Logica do carrossel
  styles/
    index.css      - Todos os estilos do site
  README.md
```

## Como usar

Abra o arquivo `src/index.html` em qualquer navegador.
